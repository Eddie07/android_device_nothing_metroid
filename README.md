# LineageOS 23.2 Device Tree for Nothing Phone (3) (`metroid`)

This repository contains the device tree for the **Nothing Phone (3)** (codenamed `metroid`), powered by the Qualcomm Snapdragon 8s Gen 4 (SM8735) SoC, tailored for **LineageOS 23.2** (Android 16).

---

## Device Specifications

| Feature | Specification |
| :--- | :--- |
| **Device Name** | Nothing Phone (3) |
| **Codename** | `metroid` |
| **SoC** | Qualcomm SM8735 (Snapdragon 8s Gen 4) |
| **CPU** | Octa-core (1x Cortex-X4 + 3x / 2x / 2x Cortex-A720) |
| **GPU** | Qualcomm Adreno 825 |
| **RAM** | 12GB / 16GB LPDDR5X |
| **Storage** | 256GB / 512GB UFS 4.0 |
| **Display** | 6.67" AMOLED, 120Hz, 1260 x 2800 pixels |
| **Rear Camera** | Triple 50 MP (Wide + Periscope Telephoto + Ultrawide) |
| **Front Camera** | 50 MP |
| **Battery** | 5150 mAh / 5500 mAh with 65W Wired Charging |
| **Shipped OS** | Android 15 (Nothing OS 3.5), upgradable to Android 16 |
